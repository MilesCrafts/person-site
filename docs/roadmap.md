## 版本与阶段关系

V2 是前后端共同交付的全栈产品版本，详细设计见 [`v2-technical-design.md`](v2-technical-design.md)：

- V2-0 对应 Phase 1 收尾：修复并冻结公开读取 API。
- V2-1 对应 Phase 2：完成公共前端真实数据验收。
- V2-2、V2-3 对应 Phase 3：管理安全和文章编辑闭环。
- V2-4 对应 Phase 3.5：将公开站改为白色主导的现代文章网站；Profile、Now Watching、Feature 和影集扩展延期。
- V2-5 连接 Phase 4/5：HTTPS、备份、部署、监控和上线验收。

V2 不等于 Flyway 的 `V2__seed_initial_content.sql`。Flyway V1/V2 已执行，新数据库变化必须新增迁移版本。

## Phase 0：项目结构和服务器准备

**目标**

建立协作边界、可信 Git 基线和不影响现有站点的服务器准备方案。

**任务**

- 建立 `frontend/`、`backend/`、`deploy/`、`docs/` 的职责和状态文档。
- 前端工程整体迁入 `frontend/`，并验证迁移前后构建产物一致。
- 用户决定创建 Git 后，再确认仓库边界并建立独立 Worktree。
- 只读盘点腾讯云、宝塔、Nginx、Java 21、PostgreSQL、端口和备份现状。
- 在授权窗口内准备并审核 `/api` 代理、HTTPS 和回滚方案。

**依赖**

用户确认未来 Git 启用时间、静态托管工作目录和线上变更窗口；取得必要但最小化的服务器访问授权。

**验收标准**

- 文档所有权和线程边界明确。
- Git 暂缓决策已记录；启用后再验收 Worktree 与无重叠写入。
- 现有前端构建与线上页面未受影响。
- `8081`、PostgreSQL 和 Nginx 方案经过只读核查及变更评审。
- 任何线上修改均有明确授权、备份、语法检查和回滚步骤。

**当前状态**

进行中：协作文档已建立，现有前端已迁入 `frontend/`；用户决定暂不创建 Git；静态托管工作目录尚待确认；线上环境未修改。

**风险**

静态托管工作目录尚未确认；错误代理可能影响 SPA 路由；未经核实开放端口会扩大攻击面。

## Phase 1：后端公开读取 API

**目标**

交付不依赖登录的内容读取 MVP，同时不影响现有 Vue 站点。

**任务**

- 在 `backend/` 初始化 Java 21 / Spring Boot 3.5 模块化单体。
- 建立 PostgreSQL schema 和 Flyway 迁移。
- 实现 taxonomy、article、home、archive、search、album 和 profile 的公开读取接口。
- 使用 DTO、Problem Details、稳定分页和 `/api/v1` 前缀。
- 建立测试、OpenAPI、健康检查和当前 Mock 数据的幂等导入方案。
- 修复文章列表查询在 PostgreSQL 下对可空搜索参数的错误类型推断，避免 `lower(bytea)`。
- 为无筛选、分类/Topic 筛选、关键词、分页、排序、详情和导航增加 PostgreSQL 回归测试。

**依赖**

Phase 0 的工作区边界；API 契约；本机隔离 schema 或 Testcontainers PostgreSQL；现有前端数据映射。

**验收标准**

- Maven 测试与构建通过。
- 空 PostgreSQL 可从零执行全部 Flyway 迁移，重复启动无错误。
- 公开接口仅返回已发布内容，分页、筛选、导航和错误响应符合契约。
- 本机 `127.0.0.1:8081` 健康检查通过，端口不对公网开放。
- `/api/v1/articles`、详情、导航、home、search 等依赖文章查询的接口在真实 PostgreSQL 下通过。

**当前状态**

已完成：Spring Boot 3.5.4 / Java 21 公开读取 API、测试基线和可执行 JAR 已实现；Flyway V1～V4 已在本机与隔离空库执行，readiness、文章列表、详情、导航、home 和 search 均通过真实 PostgreSQL 回归。Docker daemon 未运行，3 条 Testcontainers 测试仍被跳过，但隔离本机 PostgreSQL 已补充从空库迁移和全链路验收。

**风险**

契约过早变化会造成前后端返工；错误数据迁移可能改变现有 slug/URL；Flyway 破坏性迁移会降低回滚能力。

## Phase 2：前端接入真实 API

**目标**

按功能渐进替换 Mock 数据，同时保持现有页面 URL 和用户体验。此阶段已完成的 Editorial Magazine 视觉是历史实现，不再约束 V2-4 改版。

**任务**

- 建立统一 API 客户端和类型。
- 配置 Vite dev proxy，使开发和生产均通过相对地址 `/api/v1` 访问后端。
- 依次接入 taxonomy、article 列表、详情与导航、home/profile、search/archive、album。
- 增加加载、空数据、错误和重试状态。
- 保留开发期显式 Mock 开关；生产失败时不得静默显示假数据。
- 执行构建、路由和关键页面回归。

**依赖**

文章查询修复完成；稳定的 Phase 1 API；OpenAPI/DTO 契约；可用测试数据和本地/生产 `/api` 代理。

**验收标准**

- `npm run build` 通过。
- 首页、文章详情、筛选、分页、搜索、归档和影集冒烟测试通过。
- 已发布页面 URL 和 slug 不变。
- 生产构建不依赖 Mock 数据。
- 浏览器直达和刷新公开路由正常，API 失败时展示明确错误而不是假数据。

**当前状态**

已完成：统一 API client、公开 DTO、显式开发 Mock 和 Vite `/api` proxy 已投入真实数据模式。2026-08-03 对 Home、Journal、Article、Search、Archive、About 在 1280px、768px、375px 三档视口执行 18 个浏览器组合，页面加载、公开 URL、控制台和横向溢出检查通过；生产构建不包含 Mock。

**风险**

迁移目录与接入 API 同时进行会扩大排错面；响应字段或日期时区不一致可能造成展示错误；网络失败处理不足会导致空白页。

## Phase 3：管理后台和内容发布

**目标**

提供单管理员安全管理、草稿、预览、发布、撤回和分类维护能力。

**任务**

- 在当前 Vue 应用中增加 `/admin` 路由、独立布局、路由守卫和编辑状态保护。
- 实现 `/api/v1/admin/session`、服务端 Session、CSRF、权限、登录限流和审计。
- 第一批实现文章列表、新建、编辑、Markdown 预览、草稿保存、发布、撤回和归档。
- 第二批 taxonomy、首页 Feature、profile、album 和媒体管理延期；当前不阻塞文章发布闭环和 V2-4 公开站改版。
- 使用乐观锁防止并发编辑覆盖。
- 建立发布状态机和 Markdown 到安全 HTML 的流程。

**依赖**

Phase 2 真实数据接入完成；Phase 1 数据模型；管理员初始化方案；备份和安全评审。管理端可在本地 HTTP 开发，但生产开放依赖 HTTPS。

**验收标准**

- 生产管理功能只允许在 HTTPS 与 Secure Cookie 验收后开放；本地 HTTP 仅用于隔离开发验收。
- Cookie 安全属性、CSRF、未授权/无权限响应和登录限流验证通过。
- 草稿到发布再到撤回的完整流程通过，公开端只展示有效发布内容。
- 并发编辑冲突返回明确的 `409 Conflict`。
- 刷新 `/admin` 子路由不丢失页面；未登录访问被安全拦截；离开未保存编辑时有提示。

**当前状态**

V2-2 管理安全和 V2-3 文章编辑闭环已完成本地真实浏览器验收，覆盖登录、Session/CSRF、预览、草稿、编辑、发布、公开可见、撤回、归档和退出；临时验收数据已清理。Profile、Feature、Album 等扩展管理延期，生产开放仍受 HTTPS 门槛约束。

**风险**

HTTPS 未完成便上线登录会泄露凭据；富文本处理不当可能引入存储型 XSS；缺少乐观锁会覆盖内容。

## Phase 3.5：文章优先公开站改版

**目标**

将现有 Editorial Magazine 公共界面改为以文章发现、筛选、搜索和阅读为核心的现代白色个人内容站。

**核心范围**

- `/` 基础文章首页：简洁站点说明、重点文章、最新文章、分类入口和基础页脚。
- `/journal` 文章列表：分类筛选、分页和明确的 loading、empty、error 状态。
- `/article/:id` 文章详情：标题、摘要、日期、阅读时间、封面、正文和上一篇/下一篇。
- `/search` 与 `/archive` 延续现有功能并统一 2.0 视觉。
- 首页加入一个克制的 GSAP“文章卡片叠 / Article Deck”：展示最近 4～5 篇真实文章，支持点击、拖动、触控与键盘切换，并可无损降级为静态列表。
- 保持 `/about`、既有公开 URL 和文章 slug 兼容；About 不扩展为个人主页，也不作为当前主导航重点。

**明确延期**

- 个人介绍、近期状态和 Now Watching。
- 电影、足球、阅读、生活记录的独立首页模块。
- Album 首页展示、复杂影集管理和媒体扩展。
- 沉浸式长滚动开场、自动轮播及其他复杂视觉效果。
- 除 Article Deck 外的其他 GSAP 展示组件、全站滚动接管、粒子、3D 与装饰性时间线。

**视觉基线**

- 白色主背景、浅灰辅助层、深色正文和单一克制蓝色强调。
- 现代无衬线字体、稳定网格、充分留白、细边框和 12～16px 圆角。
- 不使用大面积渐变、发光阴影、毛玻璃叠层、后台侧栏、统计图表或多彩指标卡。

**验收标准**

- `npm run build` 通过。
- `/`、`/journal`、代表性文章详情、`/search`、`/archive` 在 1280px、768px、375px 验收。
- 公开 URL、文章 slug、分类语义和真实 API 契约保持兼容。
- 页面无横向溢出，键盘焦点清晰，动画尊重减少动态效果偏好。
- Article Deck 在鼠标、触控和键盘下可用；减少动态效果模式及 GSAP 不可用时呈现完整静态文章列表，且不阻塞首屏主要内容。
- loading、empty、error 和 success 状态具有统一视觉，生产失败不回退 Mock。

**当前状态**

2026-08-10 已完成公开前端实现：`/` 改为文章首页，`/journal` 保持兼容，首页不再展示 Profile、Now Watching 或 Album；首页、列表、详情、搜索、归档和兼容 About 已统一为白色现代视觉。GSAP Article Deck 已实现点击、拖动、触控、键盘、减少动态效果和静态降级路径。

`npm run build` 已通过。使用显式开发 Mock 对 6 个公开路由在 1280px、768px、375px 共 18 个组合完成 CDP 浏览器检查：全部完成加载、无页面错误、无横向溢出；Article Deck 从 `01 / 05` 正常切换至 `02 / 05`。

2026-08-11 使用关闭 Mock 的 Vite、Spring Boot 与隔离 PostgreSQL 完成真实 API 回归：作品、能力、文章、详情、搜索、归档、关于和首页共 8 个路由，在 1280px、768px、375px 下形成 24 个页面组合，观察到 30 次 `/api/v1` 响应，0 控制台/请求错误、0 横向溢出；匿名 `/admin` 守卫正确跳转登录页。Phase 3.5 标记完成。

## Phase 4：图片存储、搜索、备份和监控

**目标**

增强媒体、检索、可恢复性和可观测性，不提前引入分布式基础设施。

**任务**

- 选择 S3/R2，建立预签名上传、校验、多尺寸派生和 CDN 策略。
- 使用 PostgreSQL 完成当前规模的搜索与索引调优。
- 建立数据库与对象存储备份、保留、加密和恢复演练。
- 接入健康检查、结构化日志、requestId、基础指标和告警。
- 评估 Caffeine；仅在明确多实例需求后再考虑 Redis。

**依赖**

对象存储决策、预算、Phase 3 管理流程、服务器监控能力和恢复目标。

**验收标准**

- 上传类型、大小、尺寸和权限校验通过，敏感 EXIF 得到处理。
- 代表性搜索查询满足约定质量和性能。
- 能在目标 RPO/RTO 内恢复到新数据库，并记录演练结果。
- 关键 5xx、健康、磁盘、连接池和备份失败可被发现。

**当前状态**

未开始。

**风险**

对象存储生命周期误配会丢图；备份未经恢复测试不可信；中文搜索能力可能低于预期；无界日志会耗尽磁盘。

## Phase 5：上线验收和长期维护

**目标**

以可回滚、可观测、可恢复的方式完成上线，并建立长期维护节奏。

**任务**

- 执行测试、构建、Flyway、配置、性能、安全和浏览器验收清单。
- 灰度切换真实 API，保留上一版本构建与 JAR。
- 验证 HTTPS、缓存、SEO、RSS、站点地图和关键外链。
- 建立依赖升级、证书续期、备份恢复、容量与漏洞检查周期。
- 持续更新状态、决策记录和运行手册。

**依赖**

前四阶段完成，变更窗口、回滚包、监控和负责人就绪。

**验收标准**

- 线上关键用户路径与 API 冒烟测试通过。
- 没有公开秘密、管理端明文 HTTP、暴露的 `8081`/数据库端口。
- 回滚步骤经过演练，备份可恢复，监控与负责人明确。
- 项目文档与实际版本、端口、路径和运维方式一致。

**当前状态**

未开始。

**风险**

上线清单与实际配置漂移；依赖或证书长期不维护；数据库迁移不向后兼容导致应用无法回滚。
